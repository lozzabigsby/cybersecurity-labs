# Security Risk Overview Dashboard

## Project Overview

This Power BI dashboard provides a focused view of cybersecurity vulnerability risk. It is designed to show how vulnerability data can be analysed and presented for security teams, technical stakeholders, and management.

## Dashboard File

- `Security Risk Overview.pbix`

## Business Problem

Security teams need to understand which vulnerabilities are open, which are critical, and how risk changes over time. Raw vulnerability exports can be difficult to interpret without clear visual reporting.

This dashboard helps summarise vulnerability exposure using clear metrics and visual trends.

## Key Reporting Areas

- Total vulnerabilities
- Open vulnerabilities
- Closed vulnerabilities
- Critical vulnerabilities
- Average CVSS score
- Vulnerability trends
- Remediation status
- Risk distribution
- Location or asset-based risk view

## Tools Used

- Power BI Desktop

- Synthetic cybersecurity dataset
- Vulnerability management concepts

## Skills Demonstrated

- Vulnerability reporting
- CVSS-based risk analysis
- Power BI dashboard design
- Security KPI creation
- Trend analysis
- Remediation tracking
- Data cleaning and transformation
- Cybersecurity data storytelling

## Example Insights

The dashboard is designed to support insights such as:

- how many vulnerabilities remain open
- whether critical findings need urgent remediation
- how average CVSS score reflects overall exposure
- whether vulnerability volume is improving or getting worse
- which areas may need focused remediation work

## Dataset Note

The data used in this project is synthetic and created for portfolio and learning purposes. It does not contain real customer, company, or security incident data.
