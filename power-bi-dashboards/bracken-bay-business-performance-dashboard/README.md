# Bracken & Bay Power BI Portfolio

A business performance dashboard for Bracken & Bay Property Services Ltd, built with a synthetic practice dataset. All people, accounts and transactions are fictional, as documented in the workbook.

## Explore the project

- [View the dashboard PDF](Bracken_Bay_Business_Performance_Dashboard.pdf)
- [Download the Power BI report](Bracken_Bay_Business_Performance_Dashboard.pbix)
- [Download the Excel practice dataset](Bracken_Bay_PowerBI_Practice.xlsx)

The report contains four pages: Overview, Services, Customers and Locations. It explores revenue, gross profit, gross margin, completed jobs, customer acquisition sources and performance against revenue targets.

## Portfolio reporting period

The PDF uses January-December 2025 across all four pages, with other filters set to All. The underlying dataset contains completed jobs from 1 January 2024 to 31 August 2026 and targets through December 2026. Therefore, 2026 actuals represent a partial year.

## Selected 2025 results

| Metric | Result |
| --- | ---: |
| Revenue | £415,691 |
| Gross profit | £247,571 |
| Gross margin | 59.6% |
| Revenue target | £307,500 |
| Revenue above target | 35.2% |

These figures are reported in the dashboard PDF. Commercial contract visits generated approximately £141k in revenue, referrals generated approximately £169k, and Christchurch had the highest displayed location gross margin at 62.0%.

## Files and usage

Open the PDF for a quick review, or download the PBIX and open it in Power BI Desktop to explore the interactive report. The Excel workbook contains Jobs, Customers, Services, Employees, Targets, Locations and ReadMe sheets. Consult its ReadMe for dataset definitions.

Refreshing the PBIX on another computer may require updating its Excel source path to the downloaded workbook. The supplied project files are preserved without modification.
